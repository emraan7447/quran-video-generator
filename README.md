# Qur’an Video Generator
1. Place your background MP4s in /backend/backgrounds/ (mosque.mp4, nature.mp4, sky.mp4)
2. Run backend: npm install → npm start
3. Deploy frontend to Vercel
4. Deploy backend to Render/Railway with FFmpeg installed
5. Open frontend → select Surah, ayahs, reciter, background → Generate YouTube-ready video
